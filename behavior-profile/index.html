快速解读

使用边界：本工具依据你输入的观察与文本做启发式归纳，结论是待验证的假设，不是心理诊断，也不应用于操控、歧视或替他人做重大决定。对他人画像前应尽可能告知并获得同意。

一条观察 = 在什么情境下、做了什么、你如何解读。尽可能写事实，少写评判。

粘贴其本人书写的文字（聊天、邮件、公开表达）。系统会提取用词与句式信号，不做语义真值判断。

简版 IPIP-NEO / HEXACO 取向的自评或他评量表（36 题）。1 = 非常不同意，5 = 非常同意。未作答的题目不会计入。

数字表型取向：记录可观察的日常节律，用于区分「长期特质」与「近期状态」。

大五 + 诚实谦逊画像

分数 0–100，50 为中性参考线；每条证据的权重与置信度见下方。

推导视图：DISC 行为风格

关系与认知模式（图式 / 依恋取向）

基于你在观察解读中反复出现的主题词归纳，不是量表诊断。

情境 → 行为 共现模式

从观察记录中挖掘重复出现的组合。支持度 = 出现次数；置信度 = 该情境下此行为占比。支持度为 1 的条目只是单次观察，不能当作稳定模式。

反复出现的主题

从情境描述与行为描述的文本中统计高频主题词。

状态 vs 特质

对比早期与近期节律，判断变化更像长期模式还是短期状态。

行为倾向模拟器

输入一个假设情境，系统会结合历史共现模式、人格先验与当前状态，给出行为倾向的概率区间。

倾向估计

概率为区间估计，条形长度对应中位数。样本越少，区间越宽。

这是基于已有数据的条件概率估计，不是对某个人的确定性预测。人的单次行为受情境、当下的身体与情绪状态、对方反应等大量未知变量影响；请把它当作「提问的起点」，而不是结论。
